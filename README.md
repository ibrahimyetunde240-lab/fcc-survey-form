# Web Development Learning Survey

A personalized survey form built as the first certification project for the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project is a survey form designed to collect information about users' backgrounds, coding experience, learning preferences, and suggestions for improving the web development learning experience.

## Features

- Name, email, and age inputs
- HTML5 form validation
- Role selection dropdown
- Coding experience radio buttons
- Learning improvement checkboxes
- Additional comments textarea
- Submit button

## Technologies Used

- HTML5

## What I Learned

Through this project, I practiced:

- Creating and structuring HTML forms
- Using different input types
- Connecting labels to form controls
- Using required fields and HTML5 validation
- Creating dropdown menus
- Grouping radio buttons
- Creating checkboxes
- Collecting longer responses with a textarea
- Building a form that meets specific functional requirements
